# Reproduce the independent audit

Read REPORT.md first. This bundle contains the independent replay wrapper, arithmetic scan and outputs. It does not duplicate the original source archive or its large data. It changes no server, calls no trading API and makes no deployment.

1. Extract Claude's `PR11_b9_vs_I2_verification_package_20261117.tar.gz` and unpack its data archives per its own REPRODUCE.md. The package must contain `data/unpacked/T1.ndjson`, T2 and T3, plus `data/unpacked/d3/I2_T1.ndjson` and the other five dumps.
2. Make the source's `ws` Node dependency available in the environment. The audit used Node 24.22.3 and ws 8.22.0. Also rerun on the deployment runtime when reconciling the release.
3. Run the scripts below with the actual package path. Outputs go to a separate directory; the source files remain untouched.

```bash
node sequential_audit.js /absolute/path/to/package I2 ./audit_results
node sequential_audit.js /absolute/path/to/package B9 ./audit_results
python3 denominator_audit.py /absolute/path/to/package ./audit_results/denominator_audit.json
```

Expected main results: 8,100 rows; baseline 0 state/side differences and candidate 106, in 2 markets; candidate 25 qualifying markets versus 24 in the supplied recorded-state replay; 1 admitted row with a denominator-induced floor disagreement.

The sequential wrapper seeds only the first decision of a market with recorded LOCK25, then preserves that engine's LOCK25. Initial conditions are listed in the output. Every initial lockedSide is null; one capture starts at 242.703 seconds instead of the beginning of the recorded five minutes. It is not affected by the late-lock example. Samples are filtered at each decision time by the original ringAt helper. External inputs remain the captured inputs.

It does not recover unrecorded inter-second page decisions or turn a missing capture into a complete market. That limitation must remain explicit in a revised comparison. The baseline control demonstrates no state/side differences under this experiment; its eight internal-memory differences are recorded.

The full per-second sequential .ndjson files are generated by the scripts but omitted from this compact bundle. Summary JSON contains all differences and qualifying entries. No API credentials or private keys are included.
